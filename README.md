# Каталог настольных игр

## Возможности

* Просмотр каталога игр
* Поиск по названию
* Фильтрация по жанрам
* Подробная страница каждой игры
* Адаптивный дизайн для компьютеров и мобильных устройств

## Используемые технологии

* HTML5
* CSS3
* JavaScript (Vanilla JS)
